This seventh Fintech Spotlight guide covers the most important habit in self-custody: keeping a safe copy of your OduwaCoin wallet. Your OWC is controlled by the private keys stored in a file called wallet.dat. If your computer is lost, stolen or its drive fails and you have no backup, nobody can recover those coins for you. The steps below work for OduwaCoin Core ETINOSA v2.0.0.3 on Windows, macOS and Linux.

What you need

  • OduwaCoin Core ETINOSA v2.0.0.3 installed, from the official GitHub release page
  • At least two safe storage places, for example a USB drive kept at home and a second drive kept somewhere else
  • Your wallet passphrase, if you have encrypted the wallet
  • About 10 minutes

Where wallet.dat lives

OduwaCoin Core keeps wallet.dat in its data directory. According to the OduwaCoin Core source code, the default locations are:

  • Windows: %APPDATA%\OduwaCoin (usually C:\Users\YourName\AppData\Roaming\OduwaCoin)
  • macOS: ~/Library/Application Support/OduwaCoin
  • Linux: ~/.OduwaCoin

The same folder holds the blocks and chainstate folders and the optional settings file OduwaCoin.conf. Only wallet.dat holds your keys.

Part A: Back up your wallet

Step 1: Use the built-in backup option

Open OduwaCoin Core and choose File > Backup Wallet.... In the save window, pick your USB drive or another safe folder and give the file a clear name, such as owc-wallet-2026-11-25.dat. The app saves it as wallet data (.dat).

When it works, you will see the message "Backup Successful" with the location of the file. If you see "Backup Failed", check that the drive is connected and has free space, then try again.

Step 2 (alternative): Use the console or command line

The wallet also has a backupwallet command, which safely copies the current wallet file to a folder or file name you choose. In the app, open Help > Debug window, go to the Console tab and type, for example:

backupwallet "E:\owc-wallet-2026-11-25.dat"

If you run the daemon on a server, use ./oduwacoin-cli backupwallet "/home/you/backups/owc-wallet.dat" and then copy the file off the server.

Step 3: Make a second copy and store it safely

  • Keep at least two copies in different physical places.
  • Do not keep your only backup on the same computer as the wallet.
  • If you use cloud storage, encrypt the wallet with a passphrase first (Settings > Encrypt Wallet...).
  • Write the passphrase down on paper and store it separately from the backup file.

Step 4: Refresh your backup regularly

By default the wallet prepares a pool of 100 future keys in advance (the default keypool size in the source code), so a backup also covers addresses you create soon after it. If you create many new addresses, change your passphrase or start staking from a new address, make a fresh backup.

Part B: Restore your wallet

Step 1: Close OduwaCoin Core completely

Use File > Exit on Windows or Linux, or Command + Q on macOS. On a server, run ./oduwacoin-cli stop. Wait until the program has fully shut down. The project README also advises fully stopping OduwaCoin Core before replacing data folders.

Step 2: Keep the current wallet file

Open the data directory and rename the existing wallet.dat to something like wallet-old.dat. Do not delete it. It may still hold keys you need.

Step 3: Copy in your backup

Copy your backup file into the data directory and rename it exactly wallet.dat.

Step 4: Start OduwaCoin Core and check your balance

Start the wallet and let it finish syncing with the network. Your addresses and balance should appear once it is up to date.

If the balance looks wrong after a full sync, close the wallet and start it once with the -rescan option, which the program describes as "Rescan the block chain for missing wallet transactions on startup". For example, on Linux: ./oduwacoin-qt -rescan. Rescanning can take a while.

Safety tips

  • Never send wallet.dat, your passphrase or private keys to anyone. Real support staff will never ask for them.
  • Be careful with the dumpwallet command. It writes all your keys to a plain-text file that anyone can read. Only use it if you understand the risk, and delete the file securely afterwards.
  • Test your backup once by restoring it on a spare computer or after a reinstall, so you know it works before you ever need it.
  • Download OduwaCoin Core only from the official GitHub release page and check the SHA-256 checksum.

Troubleshooting

The backup option is greyed out: the wallet may still be loading. Wait until the main window has opened fully.

The wallet will not start after restoring: make sure the file is named exactly wallet.dat and is in the data directory, not inside a subfolder. If the file is damaged, the program has a -salvagewallet option that attempts to recover private keys from a corrupt wallet. Work only on a copy.

Balance shows zero: wait for the sync to finish, then try -rescan as described in Part B.

FAQ

Does a backup copy my coins?
No. Coins live on the blockchain. The backup protects the keys that let you spend them.

Will my existing wallet.dat work after upgrading to v2.0.0.3?
Yes. The v2.0.0.3 release notes say existing wallet.dat files work unchanged.

How often should I back up?
After you first set up the wallet, after encrypting or changing the passphrase, and whenever you have created many new addresses.

Does the blockchain bootstrap replace my wallet?
No. As our bootstrap guide explains, it replaces only blockchain data. Back up wallet.dat before using it anyway.
