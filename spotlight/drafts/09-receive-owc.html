This ninth Fintech Spotlight guide shows you how to receive OWC safely. To get paid, you need an address: a string of letters and numbers that you give to the sender. OduwaCoin Core can create as many addresses as you like, and lets you attach a private label to each one so you always know who paid you and why. These steps work for OduwaCoin Core ETINOSA v2.0.0.3 on Windows, macOS and Linux.

What you need

  • OduwaCoin Core ETINOSA v2.0.0.3 installed, from the official GitHub release page
  • A wallet that has finished syncing (see our sync guide), so incoming payments show up correctly
  • A recent backup of your wallet.dat (see our backup and restore guide)

Before you start: how OWC addresses work

An address is safe to share. It lets people send coins to you, but it cannot be used to spend them. Only your wallet's private keys, protected by your passphrase if you followed our encryption guide, can do that.

Standard OduwaCoin addresses start with the capital letter A. Payment links use the oduwacoin: prefix.

Labels are private notes. They are stored in your own wallet file and are not sent to the sender or written to the blockchain.

Part A: Create a new receiving address

Step 1: Open the Receive tab

In OduwaCoin Core, click Receive on the toolbar. Its description reads "Request payments (generates QR codes and oduwacoin: URIs)". The window explains: "Use this form to request payments. All fields are optional."

Step 2: Add a label

In the Label box, type a short name for this payment, such as "Ada – invoice 014" or "Staking pool payout". The tooltip describes this as "An optional label to associate with the new receiving address."

Step 3: Add an amount and message (optional)

If you want a specific amount, enter it in Amount. Leave it empty or zero if the sender can choose. You can also add a Message. The wallet warns that the message is shown when the request is opened but is not sent with the payment over the network.

Step 4: Leave "Reuse" unticked

Make sure Reuse an existing receiving address (not recommended) is unticked. The wallet explains that reusing addresses has security and privacy issues, and should only be used when re-creating an earlier payment request.

Step 5: Click Request payment

Click Request payment. The wallet creates a brand-new address and opens a window titled "Request payment to …" showing the payment information: the URI, the address, and any amount, label and message you entered. If your build includes QR support, a QR code also appears.

Part B: Share the address safely

Step 6: Copy or save

Use the buttons at the bottom of the window:

  • Copy Address copies just the address.
  • Copy URI copies a full oduwacoin: payment link that can include the amount.
  • Save Image... saves the QR code as a PNG file, where available.

Step 7: Check before you send it

After pasting, compare the first and last six characters with the address in your wallet, because some malware swaps copied addresses.

Step 8: Find the request again later

Every request you create appears under Requested payments history on the Receive tab. Select one and click Show (or double-click it) to open it again. Remove deletes the entry from this list only; it does not delete the address from your wallet.

Part C: Manage your receiving addresses and labels

Step 9: Open Receiving addresses

Open the File menu and choose Receiving addresses.... The window lists your addresses and labels and notes: "It is recommended to use a new receiving address for each transaction."

Step 10: Create, edit or export

  • New creates another receiving address. You will be asked for a label.
  • Right-click an address and choose Edit to change its label. For receiving addresses, only the label can be changed, not the address itself.
  • Copy copies the selected address. Right-click also offers Copy Address and Copy Label.
  • Export saves the list as a comma-separated (.csv) file, useful for bookkeeping.

Advanced: the command line

If you run the wallet from the console (Help > Debug window > Console) or oduwacoin-cli, these commands do the same job:

  • getnewaddress "label" creates a new address under a label (the wallet calls it an "account").
  • setaccount "address" "label" changes the label on an existing address.
  • getreceivedbyaddress "address" shows how much an address has received.
  • listreceivedbyaddress lists amounts received per address.

Safety tips

  • Use a new address for each payer or invoice. It protects your privacy and makes reconciliation easier.
  • Only share addresses from your own wallet. Never accept an address someone else "pre-made" for you.
  • Back up your wallet again after creating many new addresses, so your backup covers them.

Troubleshooting

"Could not unlock wallet." This can appear when you create a new address in an encrypted wallet and the passphrase is not entered. Enter your passphrase when prompted, then try again.

"New key generation failed." The wallet could not create a new key. Unlock the wallet, restart OduwaCoin Core and try again. If it persists, check that your disk is not full.

Payment not showing: wait for your wallet to finish syncing, then check the Transactions tab. Ask the sender for their transaction ID to confirm it was broadcast.

FAQ

Can the sender see my label?
No. Labels stay in your wallet file. Only the message in a payment URI is visible to someone who opens the link.

Is there a limit to how many addresses I can create?
No practical limit. All of them belong to the same wallet and add up to one balance.

Do old addresses stop working?
No. Coins sent to any of your addresses will still arrive, which is why receiving addresses cannot be deleted.
