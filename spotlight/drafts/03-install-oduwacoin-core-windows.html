You have downloaded OduwaCoin Core and confirmed its SHA-256 checksum. Now it is time to install it. This third Fintech Spotlight guide walks Windows users through setting up OduwaCoin Core ETINOSA v2.0.0.3 on a 64-bit Windows 10 or Windows 11 PC, from unzipping the download to opening the wallet for the first time. It takes about 15 minutes, plus time for the blockchain to sync.

What you need

  • A Windows 10 or Windows 11 PC (64-bit)
  • The file OduwaCoin-2.0.0.3-win64.zip from the official v2.0.0.3 release page on GitHub, already checked against SHA256SUMS. If you have not done this yet, follow yesterday's guide on downloading and verifying OduwaCoin Core first.
  • At least 5 GB of free disk space. The wallet's first-run screen asks for at least 5 GB, and the blockchain grows over time.
  • A stable internet connection

Is it an installer or a zip?

The Windows download is a zip archive, not a setup wizard. There is nothing to "install" in the traditional sense: you unzip it and run the program. We opened the official zip to confirm its contents. It holds four files:

  • oduwacoin-qt.exe: the desktop wallet with a graphical interface. This is the one most people need.
  • oduwacoind.exe: the background node (daemon) for advanced users and servers
  • oduwacoin-cli.exe: a command-line tool for sending commands to a running node
  • oduwacoin-tx.exe: a tool for creating and editing raw transactions

The release notes confirm that the Windows download now includes the daemon, command-line and transaction tools as well as the wallet app.

Step 1: Confirm the checksum one more time

Open PowerShell in your Downloads folder and run:

Get-FileHash .\OduwaCoin-2.0.0.3-win64.zip -Algorithm SHA256

The result must match the line for OduwaCoin-2.0.0.3-win64.zip in SHA256SUMS exactly. On the day we wrote this guide, that value was:

ca3dc572ba625ce53aec4d209ef53c22bb623ccf522cb52f142fb39f51c52612

Always compare against the SHA256SUMS file on the official release page rather than a value copied from any article, including this one. If they do not match, stop and download again.

Step 2: Unzip to a permanent folder

  1. Create a folder for the program, for example C:\OduwaCoin.
  2. Right-click OduwaCoin-2.0.0.3-win64.zip and choose Extract All.
  3. Click Browse, select your new folder, then click Extract.

Do not run the wallet from inside the zip file or from a temporary folder. Keep the four files together in one place.

Step 3: Start the wallet

Open the folder and double-click oduwacoin-qt.exe.

If Windows shows "Windows protected your PC": Microsoft Defender SmartScreen often warns about programs it does not yet recognise. When we inspected the official v2.0.0.3 Windows files, they did not carry a Windows code-signing certificate (the release notes mention signing only for the Mac apps), so this warning is likely. Only if your checksum matched in Step 1, click More info, then Run anyway. If the checksum did not match, do not run the file.

Step 4: Choose where your data is stored

On first launch, a Welcome window asks where OduwaCoin Core should store its data. You can choose:

  • Use the default data directory: recommended for most people. On Windows this is C:\Users\YourName\AppData\Roaming\OduwaCoin, according to the OduwaCoin Core source code.
  • Use a custom data directory: useful if your C: drive is small and you want the blockchain on another drive.

This folder holds the blockchain, your settings and, most importantly, your wallet.dat file. Write the location down. Click OK to continue.

Step 5: Allow network access and let it sync

Windows Defender Firewall may ask whether to allow OduwaCoin Core to communicate on networks. Allow it on private networks so the wallet can connect to peers. The wallet then starts downloading the blockchain and shows a progress window with the number of blocks left and the estimated time remaining. Your balance and recent transactions may not be accurate until syncing finishes.

Syncing from scratch can take a long time. The v2.0.0.3 release also offers a verified blockchain bootstrap, OduwaCoin-DB.zip (1.62 GB, blocks up to height 2,514,711), that lets you skip most of the download. A later Spotlight guide covers it step by step.

Step 6: Back up your wallet right away

Once the wallet opens, protect it before you receive any coins:

  1. Go to File and choose Backup Wallet.
  2. Save the copy to a USB drive or another safe location that is not on the same computer.
  3. Keep at least one backup offline.

If your computer fails and you have no backup of wallet.dat, your coins cannot be recovered. Encrypting the wallet with a passphrase is covered in a later guide.

Optional: create a desktop shortcut

Right-click oduwacoin-qt.exe, choose Show more options on Windows 11 if needed, then Send to and Desktop (create shortcut).

Upgrading from v2.0.0.2

The release notes say v2.0.0.3 has no consensus or network protocol changes, and existing wallet.dat files work unchanged. To upgrade: back up wallet.dat, close the old wallet completely (File, then Exit), extract the new files to your program folder, and start the new oduwacoin-qt.exe. It uses the same data directory, so your wallet and blockchain stay in place.

Troubleshooting

"Extract All" is missing: make sure the download finished and the file name ends in .zip. Right-click the file and look under "Show more options" on Windows 11.

The wallet shows no connections: check that your firewall allowed it and that your internet connection works. A later guide covers adding peers.

Not enough disk space: choose a custom data directory on a larger drive at the Welcome screen.

Safety checklist

  • Download only from github.com/ODUWAX/oduwacoin and verify the checksum every time.
  • Never share your private keys, wallet.dat file or passphrase with anyone, including people claiming to be support staff.
  • Keep regular, offline backups of wallet.dat.
