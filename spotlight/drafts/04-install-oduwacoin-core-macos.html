You have downloaded OduwaCoin Core and checked its SHA-256 checksum. This fourth Fintech Spotlight guide is for Mac users. It shows how to install OduwaCoin Core ETINOSA v2.0.0.3 on an Apple Silicon or Intel Mac. Allow about 15 minutes, plus time for the blockchain to sync.

What you need

  • A Mac running a supported version of macOS:
    • Apple Silicon (M1 or later): macOS 11 Big Sur or newer
    • Intel: macOS 10.15 Catalina or newer
  • The correct disk image from the official v2.0.0.3 release page on GitHub, checked against SHA256SUMS. If you have not done this yet, start with our guide to downloading and verifying OduwaCoin Core.
  • At least 5 GB of free disk space.
  • A stable internet connection
  • A USB drive for your wallet backup

Step 1: Find out which Mac you have

  1. Click the Apple menu in the top-left corner and choose About This Mac.
  2. Look for Chip. If it says Apple M1, M2, M3, M4 or later, you have Apple Silicon.
  3. If it says Processor followed by an Intel name, you have an Intel Mac.

Step 2: Download the matching file

The release has two Mac disk images:

  • OduwaCoin-2.0.0.3-macOS-arm64.dmg: for Apple Silicon Macs
  • OduwaCoin-2.0.0.3-macOS-x86_64.dmg: for Intel Macs

We inspected both: arm64 is native Apple Silicon code and x86_64 is Intel code. On Apple Silicon, use arm64; the Intel build would need Rosetta.

Step 3: Verify the checksum in Terminal

Open Terminal (Applications, then Utilities) and run the command for your file:

cd ~/Downloads
shasum -a 256 OduwaCoin-2.0.0.3-macOS-arm64.dmg

For an Intel Mac, replace the file name with OduwaCoin-2.0.0.3-macOS-x86_64.dmg. The result must match your file's line in SHA256SUMS. When we wrote this guide, the values were:

arm64:  45c045416554e69fab3424e040eec8225110c0918fa6d71a01c856c186cfdb12
x86_64: 95a756685d88bf89c0a8e70783dac826fad3f0119253e309c8949a37fd1aff8d

Always compare against SHA256SUMS on the official release page, not an article. If it does not match, delete the file and download again.

Step 4: Drag the app into Applications

  1. Double-click the .dmg file. A window opens showing Oduwacoin-Qt and a shortcut to your Applications folder.
  2. Drag the Oduwacoin-Qt icon onto the Applications shortcut.
  3. When copying finishes, eject the disk image: click the eject icon next to it in the Finder sidebar.

Always run the wallet from Applications, not from the disk image.

Step 5: Open the app for the first time

Open Applications and double-click Oduwacoin-Qt. If macOS asks whether to open an app downloaded from the internet, click Open only if your checksum matched.

We checked both builds: they are signed with an Apple Developer ID certificate issued to ODUWA BLOCKCHAIN SOLUTIONS LLC. The release notes also say the Mac apps are notarized by Apple, so they should open without security warnings. If macOS says the app "is damaged" or "cannot be verified", do not override it. Delete it and download again.

Step 6: Choose where your data is stored

On first launch, a Welcome window asks where OduwaCoin Core should keep its data. You can choose:

  • Use the default data directory: recommended for most people. On a Mac this is ~/Library/Application Support/OduwaCoin, according to the OduwaCoin Core source code.
  • Use a custom data directory: useful if your internal drive is nearly full.

This folder holds the blockchain and your wallet.dat file. Library is hidden by default; to open it, go to Finder, choose Go, then Go to Folder (Shift + Command + G), and paste the path above.

Step 7: Allow connections and let it sync

If the macOS firewall asks whether to allow incoming connections, click Allow. The wallet then downloads the blockchain and shows the blocks left and time remaining.

The v2.0.0.3 release also offers a verified blockchain bootstrap, OduwaCoin-DB.zip (1.62 GB, blocks up to height 2,514,711), that lets you skip most of the download. A later Spotlight guide covers it step by step.

Step 8: Back up your wallet right away

  1. In the menu bar, click File and choose Backup Wallet.
  2. Save the copy to a USB drive or other storage that is not on the same Mac.
  3. Keep at least one backup offline.

Without a backup, coins in a lost wallet cannot be recovered. Encrypting the wallet with a passphrase is covered in a later guide.

Upgrading from v2.0.0.2

The release notes say existing wallet.dat files work unchanged. Back up your wallet, quit the old app (Command + Q), drag the new Oduwacoin-Qt into Applications, choose Replace and open it. Your data directory stays the same.

Troubleshooting

"This app can't run on this Mac" or it runs slowly: you may have the wrong build. Check your chip in Step 1 and download the matching file.

The app will not open on an older Mac: the Intel build needs macOS 10.15 or newer, and the Apple Silicon build needs macOS 11 or newer.

No network connections: check your internet connection and the macOS firewall settings.

Not enough disk space: free up space or choose a custom data directory on a larger drive at the Welcome screen.

Safety checklist

  • Download only from github.com/ODUWAX/oduwacoin and always verify the checksum.
  • Never share your private keys, wallet.dat file or passphrase with anyone, including people claiming to be support staff.
  • Keep regular, offline backups of wallet.dat.

FAQ

Do I need the arm64 or the x86_64 file?
Use arm64 for Apple Silicon (M1 and later) and x86_64 for Intel Macs. Step 1 shows how to check.

Where is my wallet file on a Mac?
By default it is inside ~/Library/Application Support/OduwaCoin. Use Finder's Go to Folder (Shift + Command + G) to open it.

Can I move my wallet from Windows to a Mac?
Yes, the wallet.dat format is the same on both. Restoring a backup involves replacing files in the data directory, so a later Spotlight guide covers it step by step. Until then, keep your Windows wallet and its backup untouched.
