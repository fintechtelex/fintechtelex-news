This fifth Fintech Spotlight guide is for Linux users. It covers two setups: the OduwaCoin Core desktop wallet on a Linux PC, and the command-line node (oduwacoind) on an Ubuntu server. Both use the official ETINOSA v2.0.0.3 release. Allow about 15 minutes, plus time for the blockchain to sync.

What you need

  • A 64-bit (x86_64) Linux computer. The release notes list Ubuntu 20.04 or newer "and similar" distributions.
  • One of the two Linux files from the official v2.0.0.3 release page on GitHub:
    • OduwaCoin-2.0.0.3-linux.tar.gz (27.3 MB): the desktop wallet app plus the daemon, for Linux PCs
    • OduwaCoin-2.0.0.3-ubuntu-daemon.tar.gz (10.4 MB): command-line tools only, for Linux servers
  • At least 5 GB of free disk space and a stable internet connection
  • A terminal, and a USB drive or other safe place for your wallet backup

New to verifying downloads? Read our guide to downloading and verifying OduwaCoin Core first.

Step 1: Make a folder and download the file

Both archives unpack their files straight into the current folder, with no subfolder of their own. So create a dedicated folder first:

mkdir -p ~/oduwacoin && cd ~/oduwacoin

Then download your file and the checksum list. For a desktop PC:

wget https://github.com/ODUWAX/oduwacoin/releases/download/v2.0.0.3/OduwaCoin-2.0.0.3-linux.tar.gz
wget https://github.com/ODUWAX/oduwacoin/releases/download/v2.0.0.3/SHA256SUMS

For a server, replace the first file name with OduwaCoin-2.0.0.3-ubuntu-daemon.tar.gz.

Step 2: Verify the SHA-256 checksum

sha256sum --ignore-missing -c SHA256SUMS

You should see your file name followed by OK. When we wrote this guide, the published values were:

linux.tar.gz:         929c072c67884225c6ef8fd07bebc50e64a703e50d3549b4ae57b9039244bb34
ubuntu-daemon.tar.gz: 07c828554885f97a46c4d471cb656722c9dbb60708061d667c0a394e9b734741

Always trust SHA256SUMS on the official release page over any article. If the check says FAILED, delete the file and download it again.

Step 3: Extract the files

tar -xzf OduwaCoin-2.0.0.3-linux.tar.gz
ls

We checked the contents of both archives:

  • Desktop archive: oduwacoin-qt (the wallet app), oduwacoind, oduwacoin-cli and oduwacoin-tx
  • Server archive: oduwacoind, oduwacoin-cli and oduwacoin-tx

Confirm the version:

./oduwacoind -version

It should report OduwaCoin Daemon version v2.0.0.3-ETINOSA.

Step 4 (desktop): Start the wallet app

./oduwacoin-qt

On first launch, choose the default data directory unless your disk is nearly full. On Linux the default is ~/.OduwaCoin, which holds the blockchain and your wallet.dat file. The wallet then connects to peers and begins to sync.

If the app does not open on a minimal install, the release notes list these packages:

sudo apt-get install libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 libxcb-shape0 libxcb-shm0 libxcb-sync1 libxcb-xfixes0 libxcb-xinerama0 libxcb-xkb1 libxkbcommon-x11-0 libfontconfig1 libfreetype6

Step 4 (server): Start the daemon

./oduwacoind -daemon

In our test, the daemon started without any configuration file and created ~/.OduwaCoin automatically. Check it is running:

./oduwacoin-cli getinfo

This returns the version, block height and number of connections. Run it again after a few minutes to watch the block count rise. To shut the node down cleanly:

./oduwacoin-cli stop

Settings go in ~/.OduwaCoin/OduwaCoin.conf if you need them later. OduwaCoin uses port 26681 for peer-to-peer connections and 26682 for RPC. Keep the RPC port closed to the internet; oduwacoin-cli works locally without opening it.

Step 5: Speed up the first sync (optional)

The release also offers a verified blockchain bootstrap, OduwaCoin-DB.zip (1.62 GB, blocks up to height 2,514,711). Our next Spotlight guide covers it step by step.

Step 6: Back up your wallet

On the desktop app, click File, then Backup Wallet, and save the copy to a USB drive. On a server, stop the node first, then copy the file:

./oduwacoin-cli stop
cp ~/.OduwaCoin/wallet.dat ~/wallet-backup-$(date +%F).dat

Move that copy off the server to safe offline storage. Encrypting your wallet with a passphrase is covered in a later guide.

Upgrading from v2.0.0.2

The release notes say there are no consensus or network protocol changes, so v2.0.0.2 wallets and nodes stay compatible. Back up wallet.dat, stop the old wallet or daemon, extract the new files into a new folder and start them. Your data directory stays the same.

Safety tips

  • Download only from github.com/ODUWAX/oduwacoin and always verify the checksum.
  • Run the wallet as a normal user, not as root.
  • Never share your private keys, wallet.dat or passphrase, including with anyone claiming to be support staff.
  • Never expose RPC port 26682 to the internet.

Troubleshooting

"Permission denied" when running a file: make it executable with chmod +x oduwacoind oduwacoin-cli oduwacoin-qt.

A "GLIBC" version error: your distribution is too old. The binaries need glibc 2.29 or newer, which Ubuntu 20.04 and later provide.

"Could not load the Qt platform plugin xcb": install the packages listed in Step 4 (desktop).

No connections: check your internet connection and allow outbound traffic on port 26681.

FAQ

Which file should I download?
Use linux.tar.gz if you want the graphical wallet. Use ubuntu-daemon.tar.gz for a headless server.

Where is my wallet file on Linux?
By default it is ~/.OduwaCoin/wallet.dat. The folder is hidden; use ls -a ~ to see it.

Do I need a configuration file?
No. The daemon runs with its defaults. Create OduwaCoin.conf only when you need custom settings.

Can I run this on a Raspberry Pi?
Not with these files. The v2.0.0.3 Linux builds are for 64-bit x86 (Intel and AMD) machines.
